# Support

Thank you for using Icebrew.

Icebrew is an open-source, local-first computational research toolkit currently under active development. This document outlines how users can seek assistance, report problems, and request improvements.

## Getting Help

Depending on the nature of your issue, please use the appropriate channel.

### Bug Reports

If you encounter a bug, unexpected behaviour, installation failure, or incorrect output, please open a GitHub Issue.

[Open an Issue](https://github.com/SomSubhroN/Icebrew/issues)

Where possible, include:

- Icebrew version.
- Operating system and version.
- Python version.
- Relevant dependencies.
- The command or workflow that caused the issue.
- Expected behaviour.
- Actual behaviour.
- Steps to reproduce the issue.
- Relevant error messages or logs.

Please avoid sharing credentials, private datasets, personal information, or sensitive system details.

### Feature Requests

Suggestions for new functionality, improvements, modules, workflows, or integrations are welcome.

Feature requests should ideally describe:

- The problem being addressed.
- The proposed functionality.
- Why the functionality would be useful.
- Potential implementation considerations.
- Relevant use cases.

[Submit a Feature Request](https://github.com/SomSubhroN/Icebrew/issues)

Please check existing issues before submitting a new request.

### Installation and Environment Problems

If Icebrew fails to install, run, or diagnose your environment, please provide relevant system information.

The following command may help:

```bash
icebrew doctor
```

If the diagnostic command is unavailable, include the installation steps you followed and the error encountered.

Installation scripts and platform compatibility are currently undergoing development and validation.

### Documentation

If you find unclear, outdated, incomplete, or incorrect documentation, you may open an issue or submit a pull request.

Documentation improvements are valuable contributions.

### Security Issues

Security vulnerabilities should not be reported through public issues.

Please refer to [SECURITY.md](SECURITY.md) for the responsible disclosure procedure.

## Contributing

Users interested in contributing code, documentation, testing, or other improvements should consult:

- [CONTRIBUTING.md](CONTRIBUTING.md)
- [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)

Contributions are welcome, subject to project review and applicable guidelines.

## Support Limitations

Icebrew is maintained as an open-source project.

There is currently no dedicated support team, guaranteed response time, commercial support service, or service-level agreement.

Issues and discussions are handled at the maintainer's discretion and as time and resources permit.

The community is encouraged to help one another through constructive, respectful, and technically grounded discussions.
